# ZenfunMC Minecraft Server Website

Responsive static website starter with 14 HTML pages: Home, About, How to Play, Rules, Ranks, Store, News, Events, Vote, Staff, Gallery, FAQ, Contact, and Admin Demo.

## Customize before publishing
- Replace `ZenfunMC` with your server name.
- Replace `play.zenfunmc.net` in `assets/js/main.js` and page text with your real server IP.
- Replace `https://discord.gg/zenfunmc` with your real invite, e.g. `https://discord.gg/zenfunmc`.
- Update staff names, rank perks/prices, event dates, and vote links.
- Gallery blocks are placeholders; replace them with screenshots of your builds.

## GitHub Pages
1. Create a repository on GitHub.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published URL.

## Important
This is HTML/CSS/vanilla JavaScript. The admin panel is a UI demo, not a secure admin system. Real admin features need a backend, secure authentication, role permissions, and a database. The contact form does not send messages, store checkout is a mockup, and server status/player count is not live. Configure real links/details before launch.
